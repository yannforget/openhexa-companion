Connect an AI client

  1. In your AI client, add a remote MCP server (sometimes called a connector or an integration) with this URL:
    {{ mcp_url }}
    It uses Streamable HTTP and OAuth: there is no API key to enter.
  2. Connect. The client opens a page here, where you enter a token for each workspace it may use.
  3. To let the client analyse dataset files, allow its code sandbox to reach storage.googleapis.com (or your OpenHEXA storage host).

For better results in clients that support skills, install the openhexa-mcp skill.

Tokens you enter are stored encrypted on this server, and its operator can access them: revoke them in OpenHEXA when you stop using it.
