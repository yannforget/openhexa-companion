# Tasks 1 and 2 with 0.3.0 (2026-11-27)

Companion 0.3.0 returns the URLs of a dataset version in one call
(`openhexa_get_dataset_file_urls`, `hexa datasets urls`) and the README with the dataset
(`openhexa_get_dataset`). Tasks 1 and 2 were run again for the two companion
configurations, to compare with 0.2.0 (see the task 1 and task 2 results). The official
server didn't change and wasn't run again.

Model `openai/gpt-6.1-terra`, one session each.

All four 0.3.0 answers are correct, as with 0.2.0: the zero-dose method from the README
for task 1, and v2 rather than the partial v3, with both Bili zones apart, for task 2.

## What changed for `mcp-skill`

- The README now comes with `openhexa_get_dataset`: in task 1 the agent read the
  zero-dose method there, and in task 2 the warning about v3, without downloading them.
- One URL call per version instead of one per file: 3 calls instead of 14 in task 2.
- Fewer URLs typed by the model: 1 in task 1, 5 in task 2 (11 with 0.2.0). Output tokens
  and cost halved.

The CLI barely changed: it never handled URLs.

## Where `mcp-skill` still loses time

Almost all the time is the model writing; tools are fast. In task 2, `mcp-skill` is still
65 s slower than `cli-skill`:

| Step | Replies | Time |
| --- | ---: | ---: |
| Typing signed URLs into `curl` (first try, then again after an error) | 2 | 47 s |
| Testing whether storage is reachable before downloading | 2 | 12 s |
| Exploring: v3's files before v2, saved queries, tables, the empty dataset | 6 | 34 s |
| Computing and answering | 2 | 19 s |

In task 1, typing the one URL took 13 s of the 41 s.

## Remaining ways to save time

- **Fewer or shorter URLs (server).** The main cost left. Each signed URL is about 900
  characters, 512 of them the signature, which comes from OpenHEXA and can't be shared
  between files. Only fewer URLs (one per version, e.g. a zip) or short links served by
  the companion server would help; short links need the sandbox to reach the server.
- **Skill.** Download right away instead of testing storage first; fetch all files in
  one command or script; skip `list_dataset_files`, since `openhexa_get_dataset_file_urls`
  gives the paths; read the README in `openhexa_get_dataset` before choosing a version.
  Together, perhaps 30–40 s on task 2 (estimate).
- **Eval image.** `file` is missing: a command using it failed though the downloads had
  worked, and the agent downloaded again. That's the environment, not the tools under
  test.
- **CLI.** Little left: one `--help` lookup in task 1, and in task 2 three failed reads,
  run alongside other commands.

Single sessions: differences of a few seconds aren't meaningful; the 65 s gap on task 2
is.
